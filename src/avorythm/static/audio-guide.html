AMM VIRTUAL AUDIO ROUTE

سه 선택؛ بدون هم‌پوشانی دو صدا

این تصویر از تنظیم واقعی سیستم گرفته شده است. فقط مسیر زیر را عیناً بساز: Chrome وارد دستگاه مجازی شود، Avorythm از میکروفون مجازی بگیرد و صدای دوبله را از هدفون یا اسپیکر واقعی پخش کند.

برنامهٔ منبعGoogle ChromeOutput → Speakers (AMM Virtual Audio Device)
ورودی Avorythmصدای برنامهInput → Microphone (AMM Virtual Audio Device)
خروجی Avorythmچیزی که می‌شنویOutput → Default / Physical headphones

در ردیف Google Chrome فقط Output device را روی Speakers (AMM Virtual Audio Device) بگذار. در ردیف Avorythm.exe، Output device باید Default بماند و Input device روی Microphone (AMM Virtual Audio Device) قرار بگیرد.

تصویر مرجع واقعی

مراحل دقیق

  1. فیلم را در Chrome یا برنامهٔ منبع پخش کن تا در Volume Mixer دیده شود.
  2. Settings → System → Sound → Volume mixer را باز کن.
  3. Output برنامهٔ منبع را روی Speakers (AMM Virtual Audio Device) بگذار.
  4. در Avorythm، ورودی AMM Loopback/Virtual را انتخاب کن.
  5. خروجی Avorythm را روی Default یا هدفون واقعی بگذار و صدای اصلی را روی صفر نگه دار.

اشتباه خطرناک

  • خروجی Avorythm را روی AMM Virtual نگذار.
  • این کار صدای دوبله را دوباره Capture می‌کند و اکو/حلقهٔ صوتی می‌سازد.
  • برای شنیدن فقط دوبله، Original را ۰٪ و Dubbed را ۱۰۰٪ بگذار.

چه وقت به AMM نیاز نیست؟

اکستنشن مستقل Chrome صدای همان تب را مستقیم Capture می‌کند و هیچ Virtual Audio Device نمی‌خواهد. بخش «دوبلهٔ فایل صوتی/ویدئویی» داخل اپ نیز فایل را مستقیم با FFmpeg می‌خواند و به تنظیم Volume Mixer نیاز ندارد. این آموزش فقط برای دوبلهٔ زندهٔ برنامه‌های دسکتاپ یا مرورگر بدون اکستنشن است.
